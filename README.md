# Personal Mini-Toolkit

This project is a small menu-driven Python toolkit that includes a number guessing game, a to-do list, a simple calculator, and a word capitalizer. The goal is to practice using loops, conditionals, lists, and friendly user input/output in one complete program.

## How to run

1. Open a terminal in the project folder.
2. Run the program with:
   python toolkit.py
3. Choose a menu option and follow the prompts.

## Reflection

The hardest part of the project was planning the menu flow so each tool could return cleanly to the main loop without breaking the program. The bug that took the longest to fix was making sure invalid menu choices were handled politely instead of crashing the app. I learned that small checks early in the code prevent bigger problems later. With one more week, I would add a password manager or a mini note-taking feature to make the toolkit even more useful.
